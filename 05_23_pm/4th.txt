结构化流程设计：
	1 顺序结构
		就是代码由上到下顺序执行
	2 选择结构
		选择语句组成
		format1:
			if (con)
				body
			判断条件con是否成立，如果成立则执行body,
				如果不成立，则不执行
			
			练习：输入两个数，求最大数

		format2:
			if (con)
				body_success
			else
				body_false

			练习：输入一个数，求绝对值
	
		format3: 嵌套
			if (con1)
			{
				if (con2)
				{
					....
				}
				else
				{
					.....
				}
				....
			}
			else
			{
				if (con3)
				{
					....
				}
				else
				{
					....
				}
				....
			}

		练习：输入年份。判断是否是润年
			366 365
			能被4整除但不能被100整除或者能被400

		format4：开关语句
			if (con1)
			{
				con1_body
			}
			else if (con2)
			{
				con2_body
			}
			else if (con3)
			{
				con3_body
			}
			....
			else
			{
				all_con_flase;
			}
			
		练习：
			90 => A
			75 => B
			60 => C
			   => D

# 第三课：Vim编辑器

## 1. Vim简介

Vim是Linux下的文本编辑器，也是程序员常用的代码编辑器。

**常用场景：**
- 编辑源代码文件
- 修改配置文件
- 查看日志文件

## 2. Vim的三种模式

### 一般模式（Normal Mode）
- 打开Vim时的默认模式
- 可以进行复制、粘贴、删除、移动光标等操作

### 编辑模式（Insert Mode）
- 可以输入和编辑文本
- 左下角会显示 `-- INSERT --` 字样

### 命令行模式（Command Mode）
- 可以执行保存、退出、搜索等命令
- 左下角会显示 `:` 字样

### 模式切换

```
一般模式 → 编辑模式：按 i/I/o/O/a/A/s/S
编辑模式 → 一般模式：按 ESC
一般模式 → 命令行模式：按 :
命令行模式 → 一般模式：按 ESC 或 执行完命令
```

## 3. 进入编辑模式的按键

| 按键 | 功能 |
|------|------|
| `i` | 在光标前插入 |
| `I` | 在行首插入 |
| `o` | 在光标下一行插入 |
| `O` | 在光标上一行插入 |
| `a` | 在光标后插入 |
| `A` | 在行尾插入 |
| `s` | 删除光标所在字符并插入 |
| `S` | 删除光标所在行并插入 |

## 4. 一般模式常用操作

### 移动光标

| 按键 | 功能 |
|------|------|
| `h` | 左移 |
| `j` | 下移 |
| `k` | 上移 |
| `l` | 右移 |
| `$` | 移动到行尾 |
| `^` | 移动到行首 |
| `gg` | 移动到文件开头 |
| `G` | 移动到文件结尾 |
| `H` | 移动到屏幕顶部 |
| `M` | 移动到屏幕中间 |
| `L` | 移动到屏幕底部 |
| `ngg` | 移动到第n行 |
| `50%` | 移动到文件中间 |

### 删除操作

| 按键 | 功能 |
|------|------|
| `dd` | 删除一行 |
| `ndd` | 删除n行 |
| `dw` | 删除一个单词（光标在首字母） |
| `daw` | 删除一个单词（光标在任意位置） |
| `ndw` | 删除n个单词 |
| `d$` | 从光标位置删除到行尾 |
| `d^` | 从光标位置删除到行首 |
| `dG` | 从光标行删除到文件结尾 |
| `dgg` | 从光标行删除到文件开头 |
| `u` | 撤销上次操作 |

### 复制粘贴

| 按键 | 功能 |
|------|------|
| `yy` | 复制一行 |
| `nyy` | 复制n行 |
| `p` | 粘贴到光标下一行 |
| `P` | 粘贴到光标上一行 |

### 可视化操作

**可视化字符选择：**
```bash
v → 方向键选择 → y 复制 → p 粘贴
```

**可视化行选择：**
```bash
Shift + v → 方向键选择 → y 复制 → p 粘贴
```

**可视化块选择：**
```bash
Ctrl + v → 方向键选择 → y 复制 → p 粘贴
```

### 可视化行移动

```bash
# 选中行后移动
Shift + v → 选中 → Shift + < 左移 / Shift + > 右移
```

### 剪切操作

```bash
dd → p    # 删除一行并粘贴（相当于剪切）
```

## 5. 命令行模式常用命令

### 保存和退出

| 命令 | 功能 |
|------|------|
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:wq!` | 强制保存并退出 |
| `:q!` | 强制退出 |

### 显示行号

```bash
# 临时显示行号
:set number
# 或
:set nu

# 取消行号
:set nonu
```

**永久显示行号：**
```bash
vim ~/.vimrc
# 添加：set number
```

### 读取外部命令结果

```bash
# 读取文件内容到当前文件
:r !cat /etc/passwd

# 读取指定行范围
:r !sed -n "5,10p" /etc/passwd
```

## 6. 分屏显示

### 垂直分屏

```bash
# 同时打开多个文件（垂直分屏）
vim -O file1.c file2.c file3.c

# 在已打开的文件中添加新文件
:vsplit filename

# 切换文件
Ctrl + w 按两次

# 全部退出
:wqa
```

### 水平分屏

```bash
# 同时打开多个文件（水平分屏）
vim -o file1.c file2.c file3.c

# 在已打开的文件中添加新文件
:split filename
```

### 鼠标支持

```bash
# 启用鼠标支持
:set mouse=a
```

## 7. Vim插件：性感注释

### 安装插件

```bash
# 1. 下载插件
# Windows: Win + R → \\172.18.71.234 → share → vim.tar

# 2. 拷贝到Linux
ls /mnt/hgfs/share/vim.tar

# 3. 创建工具目录并拷贝
mkdir /tools
cp /mnt/hgfs/share/vim.tar /tools

# 4. 解压到家目录
cd /tools
tar -xvf vim.tar -C ~
```

### 使用插件

| 按键 | 功能 |
|------|------|
| `,cs` | 模块注释（性感注释） |
| `,cc` | 行注释 |
| `,cu` | 取消注释 |

## 8. C语言开发流程

使用Vim进行C语言开发的基本步骤：

```bash
# 1. 创建 .c 源文件
touch hello.c

# 2. 编辑文件
vim hello.c
# 按 i 进入编辑模式，编写代码，按 ESC，输入 :wq 保存退出

# 3. 编译文件
gcc hello.c

# 4. 执行程序
./a.out
```

**示例代码（hello.c）：**
```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

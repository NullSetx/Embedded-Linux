# 学习笔记使用说明

## 文件结构

```
课件/
├── README.md              # 主索引（从这里开始）
├── notes/                 # 整理后的学习笔记
│   ├── 使用说明.md        # 本文件
│   ├── 01-Linux基础.md    # 第一课笔记
│   └── ...
└── 1st.txt               # 原始课件/笔记
```

## 如何添加新课件

### 步骤1：保存原始笔记
将新的课件内容保存到 `课件/` 目录下，命名格式：
```
第N课.txt
```
或直接在 `1st.txt` 后面追加内容。

### 步骤2：创建整理笔记
在 `notes/` 目录下创建新的markdown文件，命名格式：
```
NN-主题名称.md
```
例如：`02-Shell命令.md`

### 步骤3：更新索引
在 `README.md` 中添加新课的链接。

## 笔记规范建议

### 标题层级
- `#` 课程标题
- `##` 主要章节
- `###` 小节

### 代码块
使用三个反引号包裹代码，并注明语言：
```bash
# bash命令
ls -la
```

```c
// C语言代码
#include <stdio.h>
```

### 表格
用于整理对比信息（如命令选项、参数说明等）

### 示例
每学完一个知识点，添加实际操作示例

## 快捷操作

### 在VS Code中使用
1. 打开 `课件` 文件夹
2. 按 `Cmd + Shift + P` 打开命令面板
3. 输入 `Markdown: Open Preview` 预览笔记

### 快捷键
- `Cmd + B` 切换侧边栏
- `Cmd + ,` 打开设置
- `Cmd + P` 快速打开文件

## 学习建议

1. **及时整理**：课后尽快将笔记整理成markdown格式
2. **多写示例**：每个命令都动手实践并记录结果
3. **建立联系**：在笔记中添加知识点之间的关联
4. **定期复习**：每周回顾之前的笔记
5. **持续更新**：发现错误或有更好的理解时及时修改

## 需要帮助？

如果在使用过程中遇到问题，可以：
- 查看 [Markdown语法指南](https://www.markdownguide.org/basic-syntax/)
- 使用 `man` 命令查看Linux命令帮助
- 搜索在线资源
